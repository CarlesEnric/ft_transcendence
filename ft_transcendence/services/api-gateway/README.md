# API Gateway Service

*[English](#english) | [Català](#català)*

---

## English

### **Description**

**Responsibility:** Single entry point for all services

### **Function**
- Proxy/reverse proxy for all microservices
- CORS and security management
- Rate limiting
- Request routing

### **Endpoints**
- Redirects all `/api/*` requests to corresponding services

### **Technologies**
- Fastify
- Nginx (optional)

---
